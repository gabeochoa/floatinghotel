Direction C — One git panel, actions as documents

No tabs at all: a single scrollable panel of collapsible sections (Zed/VS Code style). Git objects open as reviewable documents in the main pane.

  1. One accordion: Changes · Stashes · Branches · Remotes · Tags · History, with sticky headers, counts, a status summary when collapsed (2M 2U), and g + letter to jump. This replaces both tab strips and the history splitter. Collapse state persists per repo (Settings::set_section_collapsed already exists).
  2. Sync moves to a sidebar footer (↓1 ↑2 · origin/main · 4m ago, with Pull / Push / Fetch icons), like a status bar. The header keeps only repo + branch switcher.
  3. Commit is a document, not a box: ⌘↵ opens “Commit to main” in the main pane. The message sits on top, the staged diff below, and excluded files are listed explicitly. You review exactly what you commit.
  4. Stashes are reviewable: ↵ opens a stash as a diff document with Apply / Pop / Branch. Every row has a context menu (⇧F10 / right-click / ⋯).
  5. Destructive actions only in menus, always last, red, and confirmed (Drop stash…, Delete branch…). No row-level delete buttons anywhere.
L~3 weeks. Accordion with sticky headers and cross-section keyboard focus in immediate mode; virtualizing one list across sections; two new document types (commit composer, stash diff via the existing revision diff on stash@{n}); context menus for every ref kind.
